# 配图：找、画、算、生成

AI 类课程的图大多可以自绘或现场计算；**人文、医学、生物、地理、艺术等课程常常需要真实图片**（文物、标本、显微图、地图、作品、历史照片）。智能体要主动为每一页找合适的图，而不是留空或随便贴一张。

## 选图顺序（从上往下，能用上面的就不用下面的）
| 顺序 | 来源 | 适合 | 注意 |
|---|---|---|---|
| 1 | **自绘 SVG** | 流程、结构、关系、示意、图标 | 风格统一、可改、无版权问题 |
| 2 | **脚本 / 浏览器计算** | 数据图、函数曲线、模拟结果 | 数字真实，写进 sources.html |
| 3 | **老师自有素材** | 老师拍的照片、自己的课件、实验照片 | 请老师确认能用；只在课堂用的标“仅课堂使用” |
| 4 | **开放许可图库** | 文物、标本、地图、历史照片、实验装置、自然景观 | 逐张核对许可；登记作者、许可、链接 |
| 5 | **AI 生成** | 不需要“真实”的示意场景、情境插图、封面氛围图 | 页面上标“AI 生成示意”；有限制，见下 |

## 开放许可图库
| 来源 | 内容 | 许可（以每张图的页面为准） |
|---|---|---|
| Wikimedia Commons（commons.wikimedia.org） | 几乎所有学科：文物、标本、地图、历史照片、科学图 | 公有领域、CC0、CC BY、CC BY-SA 等 |
| Openverse（openverse.org） | 聚合 Flickr、Commons、博物馆等的开放许可图片 | 同上；可按许可筛选 |
| 博物馆开放获取：大都会艺术博物馆 Open Access、荷兰国立博物馆 Rijksmuseum、史密森尼 Open Access、芝加哥艺术博物馆等 | 艺术品、文物、历史文献 | 多为 CC0 / 公有领域 |
| NASA、USGS、NOAA 等美国政府机构 | 天文、地球、气象、地质 | 多为公有领域（注意例外） |
| 古籍与历史文献数字化项目 | 书影、地图、手稿 | 各馆规定不同，逐一核对 |

可以直接用：公有领域、CC0、CC BY、CC BY-SA（课件也要按相同许可共享时注意）。**默认不用**：CC BY-NC（课件若商用或公开发布有限制）、CC BY-ND（不能裁剪改动）、没有写许可的图、新闻图片、电影剧照、商标标志。

## 用脚本搜图（需要网络）
```bash
# 搜候选（Wikimedia Commons + Openverse），只保留可再分发的许可；结果存到 _img_candidates.json
python3 <skill>/scripts/find_images.py search "Terracotta Army" --n 8 --week weekNN
# 选中第 3 张：下载到 weekNN/assets/img/web/，缩放到 1600px 以内，并把作者、许可、链接登记进 week.json
python3 <skill>/scripts/find_images.py get 3 --name bingmayong --desc "秦始皇陵兵马俑" --week weekNN
```
- **搜索词用英文更准**（Commons 和 Openverse 以英文为主），必要时中英各搜一次。
- 下载前**看一眼候选**：画面是否真的对题、清晰度、有没有水印、有没有可识别的普通人（隐私）。
- 制作环境不能联网时：用网页搜索工具找到图片页面，把链接和许可列给老师，请老师下载放进 `assets/img/web/`；智能体再登记来源。
- 页脚 `data-src` 写简短来源（“图片来源：Wikimedia Commons，作者，CC BY-SA 4.0”）；完整信息由 build.py 汇总进 image-sources.html。

## AI 生成图片
如果智能体有可用的图像生成工具（或老师提供了生成服务），可以生成**示意性**插图：
- 保存到 `assets/img/gen/`，在 `week.json` 的 `images` 登记：`["内容", "AI 生成（工具名，日期）；提示词见 image-prompts.md"]`，并把提示词写进 `image-prompts.md`。
- 页面上标“AI 生成示意”。
- **不要生成**：真实人物（包括历史人物“照片”）、真实事件的“现场照片”、文物 / 标本 / 病理图这类需要真实的图、商标和受版权保护的角色、带文字的图（容易出错）。
- 科学内容（解剖结构、化学结构、电路、地图）**不要用 AI 生成**——细节常常是错的；用自绘 SVG、计算或真实图片。
- 没有生成工具时，不要假装生成：改用自绘 SVG 或开放图库。

## 登记与检查
- 每张非自制的图都在 `week.json` 的 `images` 里登记：`"文件名": ["内容", "作者 · 许可 · 链接"]`。build.py 会把未登记的标红。
- 公开发布前再检查一遍：只在课堂用的图要替换（参考 `examples/week01/` 的占位图做法）。
- 图片放进幻灯片前压缩：长边 ≤ 1600px，照片用 JPG（质量 85），一张一般不超过 400 KB。

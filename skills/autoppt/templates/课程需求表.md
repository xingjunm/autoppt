# 课程需求表（第 ⓪ 步：先了解老师要教什么）

> 给老师填，或者由智能体按这张表一问一答地问（每轮最多 4 个问题，先问最关键的）。
> 填不出来的项留空——智能体会用默认值，并在《课程内容设计》里标明“假设”，请老师确认。

## A. 基本情况（必答）
| 问题 | 回答 |
|---|---|
| 1. 课程名称、学科 | 例：中国古代史 / 有机化学 / 临床诊断学 / 人工智能基础 |
| 2. 学生是谁？ | 年级、专业、人数；先修了什么；**会不会编程** |
| 3. 一共几周？每周几节、每节多长？ | 例：16 周，每周 2 节理论 + 1 节实践，每节 45 分钟 |
| 4. 这门课最想让学生带走的 3 件事 | 能力、观念或作品 |

| 问题 | 回答 |
|---|---|

| 5b. 没有的话：按周列出想讲的主题 | 第 1 周：…… 第 2 周：…… |

## C. 怎么教
| 问题 | 回答 |
|---|---|
| 8. 实践课做什么？ | 编程实践 / 案例研讨 / 实验操作与数据分析 / 习题课 / 写作与展示 / 没有实践课 |
| 9. 有没有贯穿全学期的项目或作业？ | 每个阶段交什么 |
| 10. 考核方式 | 平时、作业、项目、考试的比例 |
| 11. 讲课风格偏好 | 案例驱动 / 故事与历史 / 推导与证明 / 问题导向 / 讨论式 |
| 12. 课件风格 | A 学术刊物 / B 黑底舞台 / C 几何色块（见 styles/styles.jpg） |

## D. 素材与环境
| 问题 | 回答 |
|---|---|
| 13. 配图从哪来？ | 老师自有图片（拍摄、旧课件）/ 允许智能体从开放许可图库搜索 / 允许 AI 生成示意图 |
| 14. 课件会公开发布吗？ | 只在课堂用 / 发给学生 / 公开到网上（决定能不能用“课堂引用”的图） |
| 15. 学生电脑与软件 | 有没有笔记本；能装 Python 吗；要用到的专业软件 |
| 16. 授课语言 | 中文 / 英文 / 双语（术语中英对照？） |

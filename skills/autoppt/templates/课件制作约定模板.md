# 《课程名》HTML 课件制作约定（智能体工作备忘）

> 放在课程文件夹根目录（或智能体的项目记忆里）。每做完一周，把**新学到的规矩、示例数据的已知结果、教师的偏好**补进来。
> 下一周开工前，智能体先读这份文件——这是“越做越快”的关键。

## 风格
- 课件风格：A 学术刊物（academic）/ B 黑底舞台（stage）/ C 几何色块（blocks）——选定：____；`new_week.py --style ____`。

## 交付
- 课件写进课程文件夹下的 `weekNN/`；首页互相链接（← 上一周 · 下一周 →）。
- 用户说“设计第 N 周的课件”= 设计文档 + 完整实现；“设计第 N 周的课程内容 / 设计文档”= 只写文档，说“开干”再实现。

## 内容
- 主线：每周一句贯穿全周的话（第 1 周：……；第 2 周：……）。
- 专业性：教师看重的方向；论文数字注明年份、模型、任务，不外推；有争议的问题两方证据都给。
- 不编造：手工示意数据标“示意”；课程组写的数据标“课程组撰写”；模型输出只来自真实运行。
- 工具中立；法律政策只陈述“截至某月”的事实。

## 版式（随实践补充）
- 代码页 `data-fit="off"`，代码行 ≤ 86 列。
- 互动页内容多时 `data-fit="off"`，否则 autofit 会把它放大到顶住标题。
- 新组件 class 用独有前缀；不要用 `.ok / .bad / .blue / .r` 这类通用名。
- 文字出处写 `data-src="资料来源：…"`。

# 人工智能基础 · 第 1 周 HTML 课件（AutoPPT 参考示例）

> **开源版说明**：这是复旦大学《人工智能基础》（2026 秋）第 1 周的真实课件。原课件中课堂教学引用的照片、新闻截图、电影剧照与片段不能公开再分发，已换成标有原内容的占位图（见 `image-sources.html`）；软件图标换成了通用图形。其余内容、讲稿、互动与代码保持原样。`第一周 设计文档.md` 是生成这套课件时用的设计文档。

按《第一周 设计文档.md》从零实现。美术方向：A「学术刊物」（2026-10-29 教师选定，选择记录见 `design/`）。

## 打开方式

- **推荐**：在本文件夹运行 `python3 start.py`（Windows：`py -3 start.py`），浏览器会自动打开 `http://127.0.0.1:8765/index.html`。只在本机提供服务。
- 也可以直接双击 `index.html` 或各课件文件打开；但演讲者视图（S 键）需要用上面的方式。
- 课件全部资源在本地，断网可用（安装软件下载、AI 接口除外）。

## 修改内容

1. 直接编辑 `lecture1.html` 等文件。每页是一个 `<section>`，教师备注在 `<aside class="notes">` 中。
2. 页眉文字来自 `data-part="主标题|副标题"`，图片来源来自 `data-src`，页码自动生成。
3. 修改后运行 `python3 build.py`：重新生成学生版、教师指南的分钟级安排、图片来源页，并按实际用字裁剪字体（需要 `fontTools` 和 Noto CJK 字体；没有时跳过，课件会使用系统中文字体）。

## 已知限制

- 实践课的软件界面是 HTML 绘制的“界面示意”，不是真实截图（已在每处标注），可按教师指南替换。
- 字体子集只包含当前课件用到的字；修改内容后新加的字若不在子集中，会自动回退到系统字体，运行 `build.py` 即可重新裁剪。
- 设计文档中的 Vite 构建未采用：课件为纯静态文件，无需 `npm install`。
- 内容与数据（`src/content/`）未单独拆分：每页内容直接写在 HTML 中，便于直接修改。

`src/deck.js` 新增 autofit：内容区（`.body` / `.stage` / `.st`）下方留白过多时，整体等比放大（最多 1.42 倍）并重新排版，字号随之变大。测量时兼顾 Windows/macOS、报错/修正、测验解析等所有状态，并保证：不越过页脚和下方结论句、不横向溢出、代码不被裁切、“复制”按钮不压字、短标题不多折行。单页关闭：`<section data-fit="off">`；单个盒子关闭：盒子上加 `data-fit="off"`。修改内容后无需手动调整，刷新即重新计算。

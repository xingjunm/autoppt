# 我的第一个 Python 程序name = "小明"daily_hours = [2, 3, 1, 4, 2, 3, 5]total = sum(daily_hours)average = total / len(daily_hours)print("你好，" + name + "！")print("本周总学习时间：", total, "小时")print("平均每天学习：", round(average, 1), "小时")if average >= 3: print("学习时间比较充足！")else: print("可以尝试合理安排更多学习时间。")

对一下：你的输出和这里一样吗？

你好，小明！ 本周总学习时间： 20 小时 平均每天学习： 2.9 小时 可以尝试合理安排更多学习时间。

正确输出（逗号后的空格是 print 自动加的）

  • 20：2+3+1+4+2+3+5，心算对得上
  • 2.9：20 ÷ 7 ≈ 2.857，保留一位小数
  • else：2.9 小于 3，所以走了“否则”这一支

本课程 AI 使用规范：可以用，但要能解释、会核验

1

可以用

用 AI 学概念、解释代码、找错误、出主意，都鼓励。

2

要能解释、会核验

交上来的每一行代码、每个结论，你都要能讲清楚，并亲自运行核对。

3

写清楚怎么用的

每份阶段文档附“AI 使用说明”：用了什么工具、做了什么、怎么核验。

AI 使用说明（示例）
工具：VS Code + Continue + GLM 模型
用途：让 AI 解释第 5 行代码；修改代码时参考了它给出的写法
核验：自己运行并用心算核对了输出；改写了一处它给错的变量名
两个“不要”
不要把身份证号、病历、他人数据、API 密钥发给 AI
考试是闭卷，靠的是你自己真懂

AI 助手怎么工作：扩展传话，模型回答，你来核验

你提问 + 代码
→
VS Code 扩展如 Continue：把问题发出去
→
大模型接口如 GLM：生成回答
→
回答
→
你来核验运行、对照、追问

扩展是“传话的”：装在 VS Code 里，负责把你的问题和代码发出去、把回答显示回来。

模型是“回答的”：运行在服务商的服务器上，需要账号和密钥（API Key）才能调用。

安装 Continue 扩展，接入一个大模型

  1. 扩展市场搜索 Continue，确认发布者，Install
  2. 在模型服务商官网注册、创建 API Key默认示例：智谱开放平台 GLM-4.7-Flash（以官方最新政策为准）
  3. 打开 Continue 侧栏 → 添加模型，按右边填写密钥填在本机，不要截图、不要上传
  4. 在 Continue 里发一句“你好”，收到回复即成功
# Continue 配置示意（config.yaml，以官方文档为准） models: - name: GLM-4.7-Flash provider: openai model: glm-4.7-flash apiBase: https://open.bigmodel.cn/api/paas/v4 apiKey: YOUR_API_KEY roles: [chat, edit]

YOUR_API_KEY 为占位符。扩展界面与配置写法会随版本变化；接口地址、模型名、是否免费以服务商官方文档为准（待授课前核验）。

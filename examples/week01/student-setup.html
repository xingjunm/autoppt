第一步　安装 Python

1
打开终端
目的
终端是用打字给电脑下命令的窗口，后面用来检查安装结果。
操作
按 Win 键，搜索 PowerShell 或“终端”，回车。按 ⌘ Command + 空格，搜索“终端”（Terminal），回车。
成功标志
出现一个有闪烁光标的窗口。
2
下载并安装 Python
目的
安装真正执行代码的 Python 解释器。
操作
打开 python.org/downloads，点黄色的 Download Python 3.x.x。运行 .exe，先勾选“Add python.exe to PATH”，再点 Install Now。双击 .pkg，一路“继续—同意—安装”，输入开机密码。
成功标志
安装程序显示安装成功。
常见错误
忘了勾选 PATH：重新运行安装包选 Modify，或卸载后重装并勾选。提示“无法打开”：在“系统设置 → 隐私与安全性”中点“仍要打开”。
3
检查版本
操作
关掉旧终端，重新打开，输入 py -3 --version（不行再试 python --version）python3 --version
成功标志
显示 Python 3. 开头的版本号。

第二步　安装 VS Code 和扩展

4
安装 VS Code
操作
打开 code.visualstudio.com 下载。运行安装程序，建议勾选“添加到 PATH”“通过 Code 打开”。解压 .zip，把 Visual Studio Code 拖进“应用程序”，再从“应用程序”打开。
成功标志
能打开 VS Code 的欢迎页。
5
安装 Python 和 Jupyter 扩展
操作
点左侧“扩展”图标（或 Ctrl/⌘+Shift+X），搜索 Python 和 Jupyter，确认发布者是 Microsoft，分别点 Install。
成功标志
两个扩展都显示“已安装”。
注意
不需要另外安装 Anaconda 或独立的 Jupyter 软件。

第三步　运行第一个 Notebook

6
新建 Notebook 并选择内核
操作
新建文件夹 week01 → VS Code 中 File → Open Folder 打开 → 新建文件 hello_ai.ipynb → 右上角 Select Kernel → Python Environments → 选刚装的 Python 3。
成功标志
右上角显示 Python 3.x。
若提示 ipykernel
点弹窗中的 Install；或在终端运行 py -3 -m pip install ipykernelpython3 -m pip install ipykernel，再重新选择内核。
7
运行代码
操作
把下面的代码复制进第一个格子，点格子左边的 ▶ 或按 Shift+Enter。也可以直接下载 hello_ai.ipynb。
成功标志
输出与下方一致。
# 我的第一个 Python 程序
name = "小明"
daily_hours = [2, 3, 1, 4, 2, 3, 5]
total = sum(daily_hours)
average = total / len(daily_hours)

print("你好，" + name + "！")
print("本周总学习时间：", total, "小时")
print("平均每天学习：", round(average, 1), "小时")

if average >= 3:
    print("学习时间比较充足！")
else:
    print("可以尝试合理安排更多学习时间。")
你好，小明！
本周总学习时间： 20 小时
平均每天学习： 2.9 小时
可以尝试合理安排更多学习时间。

第四步　接入 AI 编程助手

8
安装 Continue 并接入模型
操作
扩展市场搜索 Continue 并安装 → 在模型服务商官网注册并创建 API Key（课程默认示例为智谱开放平台 GLM-4.7-Flash）→ 在 Continue 中添加 OpenAI 兼容模型，按服务商文档填写接口地址与模型名。
成功标志
在 Continue 中发送“你好”能收到回复。
安全
API Key 只保存在自己电脑的扩展设置里；不要截图、不要发到群里、不要写进作业或 Notebook。
# Continue 配置示意（config.yaml），以 Continue 与服务商的官方文档为准

接口地址、模型名、免费额度和限流规则以服务商官方最新政策为准；这些信息由任课教师在授课前核实。

本课程的 AI 使用规范

  1. 可以用：用 AI 学概念、解释代码、找错误、出主意，都鼓励。
  2. 要能解释、会核验：交上来的每一行代码、每个结论，你都要能讲清楚，并亲自运行核对。
  3. 写清楚怎么用的：每份阶段文档附“AI 使用说明”——用了什么工具、做了什么、怎么核验。
不要把身份证号、病历、他人数据、API 密钥发给 AI。考试是闭卷。

常见问题与排错

现象可能原因与解决办法
Windows 输入 python 提示找不到，或弹出微软应用商店安装时没勾选 PATH，或被应用商店的“应用执行别名”拦截。先试 py -3 --version；不行就重新运行安装包选 Modify 勾选 PATH，或在“设置 → 应用 → 高级应用设置 → 应用执行别名”中关闭 python 的别名。
Windows 提示 py 不是内部或外部命令安装时取消了 py 启动器。改用 python --version，或重新安装并保留默认选项。
macOS 输入 python 无反应或报错Mac 上请用 python3。
版本号显示 Python 2.x用到了系统自带的旧版本。Windows 用 py -3，Mac 用 python3。
VS Code 的 Select Kernel 里找不到刚装的 Python完全退出并重启 VS Code；仍找不到时，按 Ctrl/⌘+Shift+P 输入 “Python: Select Interpreter” 手动选择。
Notebook 右上角一直没有内核 / 运行没反应确认已安装 Jupyter 扩展、已选择内核；看看格子左侧是否出现执行编号 [1]。
提示需要安装 ipykernel点弹窗里的 Install；或在终端运行上面第 6 步的命令。
pip 安装很慢或失败多半是网络问题。稍后重试，或换一个网络；不要随意使用来源不明的镜像。仍不行请联系助教。
代码报 SyntaxError，提示有非法字符手打代码时用了中文标点（如中文引号、中文括号）。请直接复制代码，或把标点改成英文半角。
报 IndentationError缩进不对：if / else 下面那一行前面要有 4 个空格。
AI 接口返回 401通常是鉴权问题：API Key 填错、多了空格或已失效。重新复制密钥。
AI 接口返回 403通常是权限或访问限制：账号未实名、该模型未开通、所在网络或地区受限。到服务商控制台检查。
AI 接口返回 429通常是请求太频繁或额度用完：等一会儿再试，或查看控制台的用量与限流说明。
提示模型不存在 / 模型名不支持模型名拼写与服务商文档不一致，或该模型已更名下线。以官方文档为准修改。

## 0. 优先级与红线

**优先级**：知识准确 > 能顺利讲满 45 分钟 > 学生看得懂、愿意看 > 视觉精美 > 动效。

**红线（违反即返工）**：
1. 不出现未经核实的数字（尤其是闭源大模型的参数量、价格、免费额度）。旧课件里的这类数字一律不用（见第 13 节）。
2. 不把 AGI 说成已实现，不把“大模型”等同于 ChatGPT，不暗示静态网页在运行真实 AI。
3. 不在课件里放任何 API Key，不设计让学生在网页里输入密钥。
4. 不从网上新下载真实人物（公众人物）的肖像照。人物只用旧课件里已有的照片，或用“姓名卡 + 线描/抽象插画”表示。
5. 不做成网页：没有滚动条、没有网页式导航栏、没有大段文字墙。
6. 第一周只“画地图”。后续周次会深入讲的内容（训练细节、CV、NLP、Transformer 结构、智能体、安全伦理）这里只点到为止，用一句话加一张图，并注明“第 X 周深入”。

## 1. 第一周在整门课中的位置

**新版课程结构（16 周）**——第一周要让学生看到这张全景图：

| 阶段 | 周次 | 主题 |
|---|---|---|

| 启动项目 | 5 | 定义问题与准备数据（个人项目从这里开始） |

| 用好大模型 | 9–12 | 迁移学习 · 大模型原理 · 用好大模型 · 智能体系统 |
| 负责任的 AI | 13–14 | AI 安全 · AI 伦理与治理 |
| 成果展示 | 15–16 | 个人项目展示与答辩 |

**考核**：平时 10%（出勤、课堂参与及练习）+ 实践 50%（四个阶段文档 + 最终展示）+ 闭卷考试 40%。
**个人项目**：“我的第一个 AI 模型：从一个感兴趣的问题到一个可用的应用”，视觉或文本方向；第 8、10、12、14 周分别交阶段文档一～四；第 15–16 周展示。
**教材**：吴飞《人工智能导论：模型与算法》（高等教育出版社，2020）；Russell & Norvig《人工智能：现代方法（第4版）》（人民邮电出版社，2022）。参考书：姜育刚、马兴军、吴祖煊《人工智能：数据与模型安全》（机械工业出版社，2024）。

**第一周本周目标**（学生能做到）：
1. 用自己的话说清 AI 是什么，能区分“人写规则”和“机器从数据中学”。
2. 说清 AI、机器学习、深度学习、生成式 AI 的关系。
3. 讲出 AI 发展的 6–8 个关键节点，以及数据、算法、算力为什么能推动 AI 进步。
4. 知道 AI 会犯错，用 AI 的结果要核验。
5. 在自己电脑上装好 Python、VS Code、Jupyter，跑通第一段代码，并用 AI 编程助手解释、找错、修改代码。
6. 知道本课程的 AI 使用规范。

**本周不讲**（留给后面）：训练与推理的细节、监督/无监督分类（第2周）；损失与梯度（第3周）；神经网络结构（第4周）；CNN、NLP、Transformer 原理（第6–8周）；智能体原理（第12周）；安全与伦理的具体攻击和治理（第13–14周）。

## 4. 视觉规范：像原生 PPT，不像网页

### 4.1 画布与母版
- 固定 16:9 画布 **1920×1080**（Reveal `width:1920, height:1080`，`margin:0`，自动等比缩放、黑边留白），任何页面都不能出现滚动。
- 安全区：四周留 96px；页脚 48px 高：左“人工智能基础 · 第1周”，中为当前章节，右为页码。
- 统一 **10 种母版版式**，所有页面必须用其中一种，不允许临时手写布局：
  1. **封面**：深色满版背景 + 大标题 + 一张主视觉图（或抽象生成图形），课程名、教师、日期。
  2. **章节页**：深蓝满版，巨大章节号（如 01）+ 章节标题 + 一句引导问题。
  3. **标题 + 要点**：最多 4 条要点，每条 ≤20 字，可逐条出现。
  4. **大图叙事**：图片满版或占 60% 以上，底部或侧边渐变遮罩上放 1–2 行说明。
  5. **图文分栏**：左图右文或左文右图（55/45）。
  6. **卡片网格**：3–6 张卡片，每张“图标/图片 + 标题 + 一句话”。
  7. **时间轴**：横向时间线，节点逐个出现。
  8. **大字金句/大数字**：一个数字或一句话占据画面中心。
  9. **左右对比**：两栏对照（如“传统编程 vs 机器学习”）。
  10. **互动页**：左侧互动画布（≥60% 宽），右侧说明与按钮；实践课另有“步骤 + 截图”“代码”两种变体。
- 每页一个核心观点。正文同时可见的文字一般不超过 60 个汉字；多了就拆页或用逐步出现。
- 内容页中至少 70% 要有图片、图示或互动，不能是纯文字页。

### 4.2 设计令牌（写在 `:root`）
- 背景：暖白 `#FAFAF7`；正文墨色 `#1B1F2A`；次要文字 `#5B6475`。
- 主色：复旦深蓝 `#0B3D91`（标题、章节页底色）；强调色：橙 `#E8590C`（只用于重点词和关键数字，一页最多 2 处）；互动色：青绿 `#0F9D8A`。
- 字体：本地打包 Noto Sans SC（思源黑体）子集作为标题与正文，回退 PingFang SC / Microsoft YaHei；代码用 JetBrains Mono 或系统等宽字体。不依赖在线字体。
- 字号（1920 画布）：页标题 52–60px 粗体；副标题 32px；正文 30–34px；注释/来源 20px；代码 26px。投影后排必须看得清。
- 圆角 16px，阴影要轻；卡片间距 32px；栅格 12 列。

### 4.3 “PPT 感”的关键细节
- **逐步出现**用 Reveal fragments，效果只用淡入、上移淡入、高亮，相当于 PPT 的“出现/擦除”；一页最多 5 步。
- 页面切换用淡入（fade），不用 3D 翻转等花哨效果；尊重 `prefers-reduced-motion`。
- 按钮做成 PPT 里的“形状按钮/标签”样式，不要网页表单风格；互动控件聚焦时阻止方向键翻页。
- 图片统一处理：圆角、统一描边或阴影，老照片可统一加轻微暖色滤镜；低分辨率图片不放大超过原尺寸 1.5 倍（宁可小放、配说明卡）。
- 每张来自外部的图在页面右下角用 18–20px 小字标来源。
- 示意图一律用 SVG 原生绘制，标注“示意”；不把虚构数据画成真实统计。

### 4.4 必须使用的 Skills 和流程

先安装（安装命令以各项目最新 README 为准，安装前先核实）：

| Skill | 作用 | 安装 |
|---|---|---|
| **huashu-design**（花叔）| 主力：HTML 幻灯片的美术方向、版式与审美评审，可导出可编辑 PPTX | `npx skills add alchaincyf/huashu-design` |
| **Impeccable**（pbakaus）| 设计质量把关：排版、间距、配色、层级，消除“AI 网页感” | 从 impeccable.style 下载 Claude Code 包，复制 `.claude/` 到项目；先运行 `/teach-impeccable` |
| frontend-design（Anthropic 官方，可选）| 前端视觉补充 | 通过 Claude Code 插件市场安装 |
| huashu-art-motion（可选，低优先级）| 做短片/动画，不是做幻灯片的。只在时间充裕时，为理论1封面做一段 15–20 秒“从电影里的AI到身边的AI”开场动画 | `npx skills add alchaincyf/huashu-art-motion`；需要 uv、FFmpeg、Playwright Chromium |

**工作流程**：
1. **美术方向**：用 huashu-design 先出 3 个风格方向，每个方向只做 3 张样张（封面、图文分栏页、时间轴页），截图后停下，请教师选定一个，再全面铺开。默认推荐方向：“学术 Keynote”——暖白底、深蓝标题、大图叙事、留白充足。
2. **建母版**：把选定方向落实为第 4.1 节的 10 种版式和 4.2 节的设计令牌，写进 `theme.css`。
3. **填内容**：按第 6–8 节逐页实现，每页写完整教师备注。
4. **设计把关**：每完成一节课，跑 Impeccable 的评审和打磨命令（如 `/critique`、`/audit`、`/typeset`、`/arrange`、`/polish`；命令名以安装版本为准）和 huashu-design 的评审，按意见修改。
5. **截图验收**：Playwright 在 1920×1080 和 1366×768 下逐页截图，检查溢出、遮挡、字号；把有问题的页列入 TESTING.md 并修复。

### 实践代码（P-13、`hello_ai.ipynb`、`hello_ai.py` 三处完全一致，必须实际运行核对输出）

```python
# 我的第一个 Python 程序
name = "小明"
daily_hours = [2, 3, 1, 4, 2, 3, 5]
total = sum(daily_hours)
average = total / len(daily_hours)

print("你好，" + name + "！")
print("本周总学习时间：", total, "小时")
print("平均每天学习：", round(average, 1), "小时")

if average >= 3:
    print("学习时间比较充足！")
else:
    print("可以尝试合理安排更多学习时间。")
```

## 10. 新增图片：来源与规则

1. 优先级：自绘 SVG 示意图 > 旧课件素材 > 免费图库（Unsplash、Pexels，许可允许课堂使用）> Wikimedia Commons（公有领域或 CC 许可，按要求署名）> 官方新闻稿/产品页截图（注明来源，用于介绍该产品）。
2. 不下载真实人物新照片（见红线 4）；不使用水印图；不用 AI 生成图冒充真实照片。若用 AI 生成插画，标注“AI 生成示意”。
3. 每张图记入 `image-sources.html`：文件名、来源链接、许可、用在哪页、获取日期。
4. 需要新找的图（汇总）：手机导航、拍照翻译、植物识别示例、课程评价示例、猫图、垃圾邮件与推荐示意、两本新教材封面、2025–2026 新模型标志、四张风险卡插画、（可选）《太空歌剧院》。
5. 图片统一压缩：照片 ≤300KB（WebP 或 JPEG，长边 ≤1920px），GIF 转 MP4/WebM 或静态图。
